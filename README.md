<hr>

<h2>📌 About the Project</h2>

<p>
This project is an <b>HR Data Analytics Dashboard</b> created using Microsoft Power BI
to analyze employee attendance and workplace presence patterns.
The dashboard provides a clear view of employee <b>Presence %, Work From Home (WFH) %,
and Sick Leave (SL) %</b> across different dates and months.
</p>

<p>
This is an <b>older project that I recently revisited and edited</b> to improve the
dashboard layout, data presentation, filtering, and overall user experience.
</p>

<h2>🎯 Project Objective</h2>

<p>
The main objective of this dashboard is to transform employee attendance data into
an interactive and easy-to-understand report that can help identify attendance
patterns, WFH trends, and sick leave behavior.
</p>

<h2>📊 Dashboard Features</h2>

<ul>
  <li>Employee Presence % analysis</li>
  <li>Work From Home (WFH) % analysis</li>
  <li>Sick Leave (SL) % analysis</li>
  <li>Daily presence trend analysis</li>
  <li>Daily WFH trend analysis</li>
  <li>Daily sick leave trend analysis</li>
  <li>Month-wise filtering</li>
  <li>Day-of-week analysis</li>
  <li>Employee-level attendance details</li>
  <li>Interactive Power BI visuals</li>
  <li>Dynamic tables for employee records</li>
  <li>Ascending and descending sorting for columns</li>
</ul>

<h2>📅 Monthly Analysis</h2>

<p>
The dashboard provides monthly analysis through interactive month selectors.
Users can switch between different months and observe how employee presence,
WFH, and sick leave percentages change over time.
</p>

<p>
The dashboard currently provides analysis for:
</p>

<ul>
  <li>April 2022</li>
  <li>May 2022</li>
  <li>June 2022</li>
</ul>

<h2>🔍 Interactive Features</h2>

<ul>
  <li>
    <b>Month Filter:</b> Select a particular month to update the dashboard.
  </li>
  <li>
    <b>Employee Details:</b> View individual employee attendance records.
  </li>
  <li>
    <b>Column Sorting:</b> Columns can be sorted in either
    <b>ascending or descending order</b> according to the user's requirement.
  </li>
  <li>
    <b>Dynamic Visuals:</b> Charts and tables update based on the selected filters.
  </li>
  <li>
    <b>Day-of-Week Analysis:</b> Identify attendance patterns across weekdays.
  </li>
</ul>
